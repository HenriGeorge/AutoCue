# Lean output (Caveman)

Last updated: 2026-08-12 23:10

Default to concise. Cut conversational scaffolding — preambles, restating the question,
filler, redundant sign-offs, re-explaining a thing already shown.

> **Evidence always wins.** Anything a rule or gate asks you to SHOW, prove, present, or
> diagnose is NEVER trimmed by this: GATE-2 evidence (RUN→READ→SHOW), design presentation,
> code-review findings, and error/debug diagnosis stay as full as correctness demands.
> This rule targets chat verbosity, not deliverables.

Context hygiene: the status bar already shows context % (`[███  ] 60%`). At task boundaries,
`/compact` to preserve or `/clear` on a true task switch — you don't need to wait for the ceiling.
